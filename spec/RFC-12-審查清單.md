# RFC-12：審查清單

每個項目 MUST 對應一條驗證規則或 RFC 條文。標示 `[自動]` 者由 CI 檢查，
審查者只需確認 CI 通過；標示 `[人工]` 者 CI 無法判斷。

## 19.1 架構審查

| 項目 | 對應 | 方式 |
|---|---|---|
| 新功能未新增 MCP 工具 | RFC-071 | [人工] |
| 未引入伺服器端狀態 | RFC-041 | [自動] RFC-186 |
| 未在應用層實作認證 | RFC-087 | [人工] |
| 未在工具層實作分頁 | RFC-086 | [人工] |
| 阻塞 I/O 不在事件迴圈上 | RFC-016 | [人工] |
| 熱路徑未新增磁碟 I/O | RFC-003 | [人工] |
| 新的架構決策已記錄 ADR | RFC-153 | [人工] |

## 19.2 Manifest 審查

| 項目 | 對應 | 方式 |
|---|---|---|
| name 為 kebab-case | VAL-010 | [自動] |
| description 說明「做什麼＋何時用」 | RFC-035 / LINT-002 | [人工] |
| description 未超過 1024 | VAL-013 | [自動] |
| version 為 SemVer | LINT-001 | [自動] |
| execution 未宣告輸出語意 | VAL-024 | [自動] |
| execution 指向的 script 存在 | VAL-022 | [自動] |
| 自訂屬性有 x- 前綴 | LINT-005 | [自動] |

## 19.3 Body 審查

| 項目 | 對應 | 方式 |
|---|---|---|
| 有可直接照抄的呼叫範例 | RFC-040c | [人工] |
| 說明如何解讀結果 | RFC-040c | [人工] |
| 說明不適用的情況 | RFC-040c | [人工] |
| 引用的 reference 都存在 | VAL-050 | [自動] |
| 未超過 32 KB | LINT-011 | [自動] |
| 無樣板語法 | RFC-061 | [人工] |

## 19.4 Script 審查

| 項目 | 對應 | 方式 |
|---|---|---|
| 每個網路呼叫有 timeout | SEC-010/011/012 | [自動] |
| 呼叫**之前**印出目標端點 | RFC-050 | [人工] |
| 長等待有心跳，間隔 < stall_timeout | RFC-080 | [人工] |
| 進度走 stderr、結果走 stdout | RFC-083 | [人工] |
| **印完立刻結束，不留尾巴** | RFC-081 | [人工] |
| 機密由 env 取得，不從 argv | RFC-089 | [人工] |
| 不寫任何檔案 | VAL-040 | [自動] |
| shell script 有 set -e 或已豁免 | LINT-020 | [自動] |
| 支援來源端過濾參數 | RFC-066 | [人工] |
| 純轉發的 script 用 bash 而非 Python | PERF-004 | [人工] |

## 19.5 安全審查

| 項目 | 對應 | 方式 |
|---|---|---|
| 無指向 Bundle 外的 symlink | SEC-001 | [自動] |
| 可執行檔只在 scripts/ | SEC-002 | [自動] |
| 環境變數封鎖清單未被放寬 | RFC-052 | [人工] |
| 新增直譯器有 ADR 與安全審查 | RFC-138 | [人工] |
| 安全測試執行真實攻擊 | RFC-163 | [人工] |
| 安全測試同時驗證未誤傷正常用途 | RFC-164 | [人工] |
| 錯誤訊息不含路徑／機密 | RFC-101 | [人工] |
| 容器非 root、唯讀、drop capabilities | RFC-059d | [人工] |

## 19.6 效能審查

| 項目 | 對應 | 方式 |
|---|---|---|

| 未在熱路徑加入 subprocess | PERF-002 | [人工] |
